# PENNYPAL
I am your cute piggy who will help you save some money.
```
ps: If you will give me carrots you will be elon musk soon hehe :)
```
### Tech stack
- Next.js
- posgresql
- prisma (orm)
- tailwindcss
- framer-motion

### Features
- Create budget
- Update Budget
- Create Expense
- Read Expense
- Update Expense
- Delete Expense

### Installation

clone the repository
```
git clone https://github.com/akshansh-kakkkar/penny-pal.git
```

Install Dependencies
```
bun install
or
npm install
```

Run the Server
```
bun run dev 
or
npm run dev
```
